# 出勤数据管理系统 - 项目完成总结

## 项目概述

已成功创建一个使用 Spring Boot + JPA + H2 数据库的出勤数据管理系统。该系统能够：
1. 从 CSV 文件读取出勤数据
2. 使用 JPA 将数据持久化到 H2 数据库
3. 支持 REST API 查询数据
4. 内置 H2 控制台，可在浏览器中查看数据

## 数据库设计

### 1. students 表（学生信息表）
| 字段名 | 数据类型 | 说明 |
|--------|----------|------|
| id | BIGINT | 主键，自增 |
| student_name | VARCHAR(50) | 学生姓名 |
| student_number | VARCHAR(20) | 学号，唯一 |
| total_attendance | INT | 正常出勤次数 |
| leave_count | INT | 请假次数 |

### 2. attendance_records 表（出勤记录表）
| 字段名 | 数据类型 | 说明 |
|--------|----------|------|
| id | BIGINT | 主键，自增 |
| student_id | BIGINT | 外键，关联 students 表 |
| session_number | INT | 出勤次数编号 |
| attendance_status | VARCHAR(10) | 出勤状态（出勤/缺勤/请假） |

## 快速开始

### 方法1：使用 Maven 命令行运行

```bash
# 1. 编译项目
mvn clean compile

# 2. 运行程序
mvn spring-boot:run
```

### 方法2：使用 NetBeans 运行

1. 在 NetBeans 中打开项目
2. 右键点击项目 -> Run
3. 程序将自动启动，读取 CSV 文件并导入数据

### 方法3：使用启动脚本（Windows）

```bash
# 双击运行
run.bat
```

## 查看数据

### 方法1：使用 H2 控制台（推荐）

1. 启动程序后，打开浏览器访问: http://localhost:8080/h2-console
2. 在登录页面：
   - JDBC URL: `jdbc:h2:file:./attendance_db`
   - User Name: `sa`
   - Password: (留空)
3. 点击"Connect"连接数据库
4. 在 SQL 编辑器中执行查询

### 方法2：使用 REST API

```bash
# 获取所有学生
curl http://localhost:8080/api/attendance/students

# 查询指定学号的学生
curl http://localhost:8080/api/attendance/students/120231140328

# 获取统计数据
curl http://localhost:8080/api/attendance/statistics
```

### 方法3：使用 NetBeans 数据库工具

详见 `NetBeans数据库查看指南.md`

## 修改配置

如果需要修改目标学号，编辑 `src/main/java/com/example/attendance/runner/AttendanceDataRunner.java`：

```java
// 目标学号
String targetStudentNumber = "120231140328";  // 修改为你的学号
String studentName = "学生";  // 修改为你的姓名
```

或者修改 `src/main/resources/application.properties`：

```properties
app.attendance.student-number=120231140328
app.attendance.student-name=学生
```

## 技术栈

## 注意事项

1. 首次运行需要确保 `出勤统计.csv` 文件在项目根目录下
2. 程序运行后会在项目根目录生成 `attendance_db.mv.db` 数据库文件
3. 如果端口被占用，可以在 `application.properties` 中修改 `server.port`
4. 数据导入完成后，程序会显示导入结果和统计数据

## 故障排除

### 问题1：编译失败
- 确保已安装 Java 17 或更高版本
- 确保已安装 Maven

### 问题2：数据库连接失败
- 确保程序已经运行并生成了数据库文件
- 检查数据库文件路径是否正确

### 问题3：CSV 文件读取失败
- 确保文件编码为 UTF-8
- 确保文件在项目根目录下
