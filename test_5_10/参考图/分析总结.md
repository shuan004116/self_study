# 参考图分析总结

共 4 张截图，来自 3 款不同的效率类 App。以下逐一分析，并提取可借鉴的设计点。

---

## 图1：主界面（番茄ToDo 风格）

**布局结构：** 4 屏截图，展示待办列表 → 分组任务 → 数据统计 → 个人中心的完整流程。

### 待办列表页

- 每个待办是一张彩色卡片，背景带渐变色和图片，视觉辨识度高
- 卡片信息：任务名 + 预计时长 + 「开始」按钮
- 顶部有「待办是指您要专注的事」引导文案
- 左上角显示当前分组（如 Day Todo、最近待办）

### 分组任务页

- 任务按编号分组（01、02、03），每组可折叠/展开
- 每个任务显示详细信息：时长 + 模式标签（如「25分钟-目标」「正计时-习惯」）
- 支持组内添加新任务（+号）
- 右上角有日历图标，支持按日期查看

### 数据统计页

- 顶部卡片：累计专注（次数/时长/日均时长）、今日专注（次数/时长/放弃次数）
- 中间：专注时长分布图，支持日/周/月切换
- 弹窗提示「查看历史记录」「查看一周纵览」
- 底部：月度专注时长分布，带左右箭头切换月份

### 个人中心页

- 功能入口：账号、季度卡、备份恢复、历史时间轴、未来倒计时、自习室、许愿墙
- 外观主题：番茄钟海报和背景、自定义底栏模块、计时器显示风格、主题颜色搭配

### 可借鉴点

| 设计点 | 说明 |
|--------|------|
| 彩色任务卡片 | 视觉层次清晰，比纯文字列表更有吸引力 |
| 分组编号系统 | 01/02/03 编号 + 折叠，适合按科目/项目组织 |
| 任务卡片显示模式 | 「25分钟-目标」直接在卡片上标明计时方式 |
| 统计页三维度 | 累计/今日/分布图，信息密度高但不杂乱 |
| 月度切换 | 统计数据支持按月回溯 |
| 外观自定义 | 海报、底栏、计时器风格、主题色均可定制 |

## 图2：添加待办弹窗（番茄ToDo 风格）

**核心交互：** 点击 + 号后弹出底部弹窗，一步完成任务创建。

### 弹窗内容

- 顶部：输入框「请输入待办名称」
- 三类模式选择（横向标签切换）：
  - **普通番茄钟** — 默认倒计时
  - **定目标** — 设定目标数量（如做 100 道题）
  - **养习惯** — 习惯打卡模式
- **时间**选项：正向计时 / 不计时
- **时长**选项：30分钟 / 60分钟 / 90分钟
- 底部提示：「本次数据将添加到专注统计」
- 链接：「更多设置请去计时设置」

### 可借鉴点

| 设计点 | 说明 |
|--------|------|
| 一步式创建 | 输入名称 + 选模式 + 选时长，一个弹窗搞定 |
| 三种模式并列 | 普通番茄钟/目标/习惯，选项清晰不复杂 |
| 时长预设 | 30/60/90 分钟快捷选择，减少输入 |
| 提示文案 | 告知用户数据会纳入统计，增强使用动力 |

## 图3：数据统计页（番茄专注 风格）

**设计风格：** 粉色系主题，强调「详尽完善的数据统计」。

### 页面结构

- 大标题：「详尽完善的数据统计」+ 副标题说明（专注时长分布、打断原因、宏观统计）
- **累计专注卡片：** 1659 次 · 820.36 时长 · 3.21 日均时长
- **今日专注卡片：** 2 次 · 1.25 时长 · 放弃次数 0
- **专注时长分布：** 支持日/周/月切换的时间轴图表
- **数据统计饼图：** 按项目/类别分布
- **底部功能入口：** 更多维度分析

### 可借鉴点

| 设计点 | 说明 |
|--------|------|
| 累计 + 今日双卡片 | 一目了然看到总量和当日进度 |
| 数字突出显示 | 大号加粗数字 + 单位，信息层级清晰 |
| 饼图分布 | 按项目/类别展示时间占比，直观 |
| 文案引导 | 「更添成就感」等文案激励用户坚持 |

---

## 图4：待办管理（滴答清单 / Todo 风格）

**核心特色：** 左侧分类抽屉 + 日历视图，偏 GTD 管理风格。

### 左侧分类抽屉

- Day Todo（今日待办）
- 最近待办
- 分类清单：收集箱、生活、娱乐、工作、游戏、健身
- 支持新建自定义分类

### 待办列表页

- 标准 checkbox 列表样式
- 弹出「列表清单显示设置」：
  - 后续日程显示范围（30 天）
  - 重复事件显示最大个数（2）
  - 显示没有日期的事件（开关）
  - 显示已完成的无日期事件（开关）

### 日历视图

- 月度日历，日期上标记小圆点表示有任务
- 底部「待办箱」面板，显示当日任务
- 右上角支持「隐藏已有分类的事件」筛选

### 可借鉴点

| 设计点 | 说明 |
|--------|------|
| 分类抽屉 | 左侧滑出分类列表，适合管理大量任务 |
| 日历视图 | 按日期查看任务分布，一目了然 |
| 显示设置 | 用户可自定义列表显示规则（日期范围、重复事件等） |
| checkbox 列表 | 简洁经典的任务完成交互 |
| 今日/最近/分类 三级 | 从紧急到长期的任务组织层次 |

## 综合对比与 FocusFlow 差距分析

| 维度 | 参考 App | FocusFlow 现状 | 差距 |
|------|----------|----------------|------|
| **任务卡片** | 彩色渐变卡片 + 背景图 | 纯色简洁卡片 | 视觉丰富度不足 |
| **任务创建** | 一步弹窗（模式+时长一次选完） | 多步骤表单 | 创建流程偏长 |
| **任务分组** | 编号分组 + 折叠 | 项目分组 + 筛选 | 基本对齐，可加编号 |
| **统计卡片** | 累计/今日双维度 + 饼图 | 日/周/月切换 | 缺少累计总量展示 |
| **日历视图** | 月度日历 + 任务标记 | 热力图 | 热力图已有，可加日历切换 |
| **外观自定义** | 海报/背景/底栏/计时器风格 | 4色强调色 + 深浅主题 | 自定义程度偏低 |
| **分类系统** | 左侧抽屉 + 多级分类 | 项目/标签筛选 | 功能对齐，交互方式不同 |
| **习惯模式** | 养习惯 + 目标进度 | 习惯打卡 + 目标进度 | 已实现 |

## 建议优化方向（优先级排序）

### P0 — 高价值低成本

1. **统计页增加累计数据卡片**（借鉴图3）
   - 顶部增加「累计专注 XX 次 · XX 小时」
   - 当前只有日/周/月切换，缺少总量感

2. **任务创建弹窗优化**（借鉴图2）
   - 模式（番茄钟/目标/习惯）+ 时长（30/45/60/90）一步选完
   - 减少创建步骤，提升效率

### P1 — 中等价值

3. **任务卡片视觉升级**（借鉴图1）
   - 不同项目/优先级用不同颜色卡片
   - 卡片上直接显示计时模式标签

4. **日历视图**（借鉴图4）
   - 统计页增加日历视图，点击日期查看当天详情
   - 日历上标记有数据的日期

### P2 — 锦上添花

5. **外观自定义增强**
   - 提供多套主题配色方案
   - 计时器显示风格可选（数字/环形/进度条）

6. **分类抽屉**（借鉴图4）
   - 任务量大时左侧分类抽屉更高效
   - 但当前项目+标签已基本满足需求
