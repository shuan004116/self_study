FocusFlow — 智能桌面学习专注平台 · 整体框架设计文档

一、项目概述

产品名称： FocusFlow


产品类型： 桌面端学习专注与时间管理软件


技术路线： Electron + React + TypeScript


核心定位： 面向学生、考研/考公备考者及终身学习者的智能化桌面学习伴侣，集成番茄工作法、待办管理、音乐伴学、知识管理与数据复盘于一体。


设计理念：

极简克制，零干扰界面
深度集成音乐生态，解决学习背景音痛点
引入科学学习方法论工具（费曼笔记、艾宾浩斯复习等）
数据驱动的个人成长可视化

三、核心功能模块详细设计

3.1 智能番茄钟系统

功能描述：
基于经典番茄工作法（25分钟专注 + 5分钟短休息 + 20分钟长休息），提供高度可定制的专注计时体验。


核心功能清单：

支持自定义专注/短休息/长休息时长
支持正向计时与倒计时两种模式
番茄钟与具体待办任务绑定，完成自动记录耗时
连续完成4个番茄后自动触发长休息
休息时段提供眼部放松、颈椎活动指导（文字+可选语音）
支持暂停、跳过、提前结束操作
专注中被打断时，支持快速记录打断原因（标签选择：消息通知、疲劳、环境噪音、其他）
番茄钟完成时，提供温和的系统通知 + 可选音效
支持快捷键全局操控（开始/暂停/重置）
支持系统托盘常驻，最小化后仍在后台运行

核心状态管理（timerStore）关键字段：

  status: 'idle' | 'focused' | 'shortBreak' | 'longBreak' | 'paused'

}


3.2 高级待办清单系统

功能描述：
支持多层级任务管理、智能排期、拖拽排序，帮助用户从宏观规划到微观执行全面掌控学习进度。


核心功能清单：

无限层级任务结构：项目 → 任务 → 子任务
每个任务可设置：标题、描述、优先级（P0-P3）、截止日期、标签、预估番茄数、实际番茄数
支持任务拖拽排序与跨层级拖拽
"今日聚焦"看板：从所有任务中筛选今日需完成项
"艾维利时间管理法"视图：强制每日选择6项最重要的事
日历视图：按日/周/月查看任务排期
甘特图视图：可视化项目进度与依赖关系
任务搜索与高级筛选（按标签、日期、优先级、状态）
任务完成自动同步到统计模块
支持批量操作（标记完成、删除、移动）

3.3 沉浸式音乐集成中心

功能描述：
安全、合规地接入主流音乐平台，提供无干扰的纯音乐播放体验，让音乐成为专注力的催化剂而非干扰源。


核心功能清单：


平台接入层：

集成QQ音乐（通过官方开放平台API）
集成网易云音乐（通过官方API）
集成Spotify（通过Web API）
所有平台通过OAuth 2.0授权，用户可随时解绑
支持同时绑定多个平台，在播放器中切换音源

播放器功能：

完整播放器控件：播放/暂停、上一曲/下一曲、进度条拖动、音量调节
播放模式：顺序播放、随机播放、单曲循环、列表循环
收藏歌曲至FocusFlow内部收藏夹
支持播放历史记录

智能伴学功能：

场景化歌单推荐引擎：根据用户标记的任务类型（阅读、编程、背诵、写作等），推荐适配的无歌词/轻音乐歌单
专注模式联动：开启番茄钟后，自动播放预设歌单并进入"纯净播放"模式，屏蔽娱乐性界面元素
音乐专注数据记录：记录每次专注时段使用的歌曲/歌单，分析不同音乐对专注时长的潜在影响
支持本地音乐文件导入播放

内置白噪音：

内置高清白噪音库：雨声、海浪、森林、咖啡馆、图书馆、壁炉等
白噪音可与外部音乐叠加播放，独立调节各自音量
支持自定义混音：选择两种环境音并调节混合比例

3.4 智能知识笔记模块

功能描述：
支持在专注过程中快速记录灵感与疑问，专注结束后进行知识整理，并通过费曼学习法工具和艾宾浩斯复习计划巩固学习成果。


核心功能清单：


快速速记（QuickNote）：

番茄钟专注过程中，通过快捷键呼出极简速记窗口
支持纯文本与简单Markdown
速记自动关联当前专注任务与时间戳
专注结束后，提示用户归档或转化为正式笔记

费曼学习法工具（FeynmanMode）：

选择一个知识主题，进入"教学模式"
用户用简单语言复述核心概念（文本或语音输入）
系统提供"简化检查"提示：是否使用了过多专业术语？能否让一个外行人听懂？
生成"费曼卡片"，存储到知识库

艾宾浩斯复习计划：

对标记为"需复习"的笔记/知识点，自动生成复习时间表
复习间隔：1天、2天、4天、7天、15天、30天
复习提醒集成到待办清单与系统通知
每次复习后标记掌握程度，动态调整后续间隔

知识资料索引：

支持拖入PDF、Word、网页链接等资料
建立个人知识库，支持按标签分类
在专注任务时可一键调出关联资料（侧边栏展示）

-- 项目表
CREATE TABLE projects (

-- 任务表
CREATE TABLE tasks (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    description TEXT DEFAULT '',
    status TEXT DEFAULT 'todo',
    priority TEXT DEFAULT 'P2',
    parent_id TEXT REFERENCES tasks(id),
    project_id TEXT REFERENCES projects(id),
    due_date TEXT,

    created_at TEXT NOT NULL,

    completed_at TEXT
);

-- 任务标签关联表
CREATE TABLE task_tags (

);

CREATE TABLE tags (
    id TEXT PRIMARY KEY,

    color TEXT NOT NULL

);

-- 笔记标签关联表
CREATE TABLE note_tags (

七、核心Hook设计

7.1 useTimer Hook

text
text
useTimer():
  - state: { status, timeRemaining, totalTime, completedPomodoros }
  - start(taskId, duration): 开始专注
  - pause(): 暂停
  - resume(): 继续
  - stop(): 停止
  - skipBreak(): 跳过休息
  - progress: number (0-1百分比)
  - formattedTime: string (MM:SS)

7.2 useMusicPlayer Hook

text
text
useMusicPlayer():
  - state: { currentTrack, isPlaying, volume, mode }
  - play(track?): 播放指定或当前歌曲
  - pause(): 暂停
  - next(): 下一曲
  - previous(): 上一曲
  - setVolume(vol): 调节音量
  - setMode(mode): 切换播放模式
  - search(query): 搜索歌曲
  - loadPlaylist(playlistId): 加载歌单
  - connectSource(sourceId): 连接音乐平台
  - toggleWhiteNoise(type): 开关白噪音
  - setWhiteNoiseVolume(vol): 白噪音音量
