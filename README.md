# Git & GitHub 使用指南

> 📌 VS Code 用户的 GitHub 日常操作手册。

---

## 核心概念

```
你的电脑（本地）  ←→  GitHub（云端）
     ↓                    ↓
   Git 工具            网站/仓库
```

- **Git** = 本地的版本控制工具（记录代码历史）
- **GitHub** = 云端的代码托管平台（备份+协作+展示）

---

## 日常使用流程（VS Code）

### 第一步：打开源代码管理面板

快捷键 `Ctrl + Shift + G`，或点击左侧栏第三个图标（分支形状）。

### 第二步：暂存文件

- 「更改」列表显示所有修改过的文件
- 点文件右侧的 **`+`** 号暂存单个文件
- 点上方的 **`+`** 号一键暂存所有文件

> ⚠️ 已加入 `.gitignore` 的文件（如隐私数据）不会出现在这里，不用担心误提交。

### 第三步：填写提交信息

在顶部输入框写一句话描述你改了什么，比如：
```
添加考勤统计功能
```

### 第四步：提交

点输入框右侧的 **✓（对勾）** 按钮，或按 `Ctrl + Enter`。

### 第五步：推送

- 左下角点击同步图标 ↑↓
- 或点 **`···`**（三个点）→ **Push**
- 或 `Ctrl + Shift + P` 输入 `push` 选择 **Git: Push**

## 常见问题

### Q1：push 失败？
`···` → Pull（先拉取）→ 再 Push。

### Q2：不想提交某些文件？
在项目根目录的 `.gitignore` 文件中添加忽略规则，已配置的隐私文件不会被跟踪。

### Q3：提交信息写错了？
`Ctrl + Shift + P` 输入 `amend`，选择 **Git: Commit Amend**。

### Q4：想回退到之前的版本？
`Ctrl + Shift + P` 输入 `checkout`，选择 **Git: Checkout to**，选择要回退的提交。

## 隐私文件保护

以下类型的文件已加入 `.gitignore`，不会被推送到 GitHub：
- 考勤/出勤 CSV
- 工资/薪资 CSV
- 个人信息/成绩 CSV
- 证书密钥文件（`.id`、`.pem`、`.key`）

如有新的隐私文件类型需要加入，编辑 `.gitignore` 即可。
